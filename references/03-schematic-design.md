# 03. 原理图设计（Schematic Design）

全流程的第 4 步。选型（01）与环境搭建（02）完成后，把"MCU + 电源 + 外设"画成一张能用的原理图：符号摆对、网络连对、电源接对，再跑一次 ERC。输入：`docs/product-contract.md` 与选型结论；输出：一份通过 ERC、可导出 BOM 的原理图工程（`hardware/` 目录下），为 04 的 PCB 布局做准备。

> 本环节只画**原理图（schematic）**，不碰 PCB 走线。原理图是"逻辑连接图"，告诉 EDA 软件"哪根引脚连到哪根引脚"；物理摆放和走线是 04 的事。

## 目标与通过标准

- 目标：用立创EDA（推荐）或 KiCad，画出一张 ESP32-S3 最小系统 + 本产品所需外设的原理图，并通过 ERC 电气规则检查、导出 BOM。
- 通过标准：
  - 能说出自己用的是立创EDA专业版还是 KiCad，并完成下载/注册、新建工程。
  - 原理图里电源域（USB 5V → 3.3V LDO）、ESP32-S3 模组、BOOT/EN/下载电路、USB（GPIO19/20）全部画齐。
  - 所需外设（按键/LED/麦克风/功放/传感器等）的符号与网络连接正确。
  - ERC 无 Error（Warning 可逐条确认后忽略），BOM 可导出。
  - 能对照数据手册说清每个关键芯片"引脚功能、绝对最大额定值、典型应用电路"三处看了什么。

### 3.3 ESP32-S3 最小系统原理图清单

画最小系统时，按下表逐项核对（这是原理图的"骨架"，一个都不能少）：

| 模块 | 必画内容 | 说明 |
| --- | --- | --- |
| 电源输入 | USB 5V（VBUS）→ 3.3V LDO（如 AMS1117-3.3 / ME6211 / RT9013） | LDO 输入/输出各放 10µF + 0.1µF 电容 |
| 去耦电容 | 模组 3V3 引脚旁放 10µF + 0.1µF，每个 VDD 引脚就近 0.1µF | 去耦电容要**紧贴芯片电源脚**（04 环节再落实位置） |
| 模组 | ESP32-S3-WROOM-1 **N16R8**（16MB Flash + 8MB PSRAM） | 天线区域在 04 环节做净空，原理图阶段不连 |
| BOOT 电路 | GPIO0 接一个按键到 GND（下载模式），并加 10kΩ 上拉到 3V3 | 按住 BOOT 再上电进下载模式 |
| EN/RST 电路 | CHIP_PU（EN）接一个按键到 GND，加 10kΩ 上拉 + 0.1µF 到 GND 防抖 | 复位键 |
| USB 下载 | D+ = GPIO20，D- = GPIO19（ESP32-S3 原生 USB） | 接 USB-C 座子的 D+/D-，VBUS 5V，GND |
| Strapping 引脚 | GPIO0/GPIO3/GPIO45/GPIO46 按数据手册要求上下拉 | 启动模式脚，别乱接 |
| 未用脚 | 悬空或接 GND，不强行引出 | 节省调试复杂度 |

### 3.4 常用外设原理图速查

| 外设 | 接法要点 | 常见坑提醒 |
| --- | --- | --- |
| 按键 | 一端接 GPIO，一端接 GND；GPIO 内部/外部 10kΩ 上拉到 3V3；并联 100nF 消抖电容 | 默认按下=低电平；消抖电容 100nF 即可 |
| 旋转编码器 | A/B 相各接一个 GPIO，公共端接 GND，内部上拉；按钮脚同按键 | A/B 相接反只是旋转方向反，不致命 |
| WS2812 灯带 | DIN 接 GPIO，VCC 接 5V（**不是 3.3V**），GND 共地 | 数据串电阻 330~470Ω；电源域与 MCU 不同时注意电平 |
| I2S 麦克风 INMP441 | VDD=3.3V，SD 接数据 GPIO，SCK/WS 接 I2S 时钟脚，L/R 接 GND（左声道） | 时钟线短而直，麦克风模拟地干净 |
| 功放 MAX98357A | Vin=5V（或 3.3V 看型号），LX 接喇叭，DIN/BCLK/LRC 接 I2S | 喇叭功率与功放匹配，GND 接好 |
| 蜂鸣器 | 有源蜂鸣器：GPIO → NPN 三极管驱动（不要直接 GPIO 推）；无源：需 PWM | 直接用 GPIO 推蜂鸣器会烧脚 |
| 传感器接口 | I2C（SDA/SCL 各 4.7kΩ 上拉到 3.3V）或 UART（TX/RX） | I2C 上拉电阻别忘 |

> **电源域思想（参考 EasyInput 的 GPIO8 共享电源域做法）**：WS2812 用 5V、MCU 用 3.3V 时，原理图上要清楚画出两个电源网络（`+5V`、`+3V3`）和共地点；不要把 5V 直接灌到 GPIO。AI 生成原理图清单时，让它把每个外设的电压域单独列出来。

### 3.5 读原理图的方法（看懂别人/AI 给你的图）

拿到一张原理图，按这个顺序读：

1. **找电源入口**：USB/电源座 → LDO → `+3V3`/`+5V` 网络符号。电源符号（VCC/GND）只是"名字相同就相连"，不画线。
2. **找核心 MCU/模组**：认主芯片，数它的电源脚、地脚、晶振（若用裸芯片）。
3. **找网络标签（Net Label）**：标签名相同 = 电气相连。比如 `TXD0`、`GPIO8`、`I2S_SCK`，靠名字连，不靠画线。
4. **对照数据手册看三处**：
   - 引脚功能（Pin Assignments）：这个脚是 GPIO / 电源 / 输入还是输出。
   - 绝对最大额定值（Absolute Maximum Ratings）：别超过电压/电流。
   - 典型应用电路（Typical Application）：芯片厂推荐怎么接，照着画最稳。

### 3.6 ERC 检查与 BOM 导出

- **ERC（电气规则检查）**：立创EDA专业版顶部菜单 → 设计 → 电气规则检查（ERC）；KiCad：Inspect → Electrical Rules Checker。把 Error 全部清零；Warning 逐条看，确认是"故意不接"（如未用脚悬空）再忽略。
- **导出 BOM**：立创EDA：顶部菜单 → 导出 → BOM（可直接对接嘉立创采购清单）；KiCad：Tools → Generate BOM。检查每个器件都带了立创商城编号或供应商型号。

## 常见坑

1. **现象**：ERC 报一堆"未连接引脚（Unconnected pin）"。**原因**：放了符号但没连线，或网络标签拼写不一致（如 `GPIO8` 和 `GPIO8 ` 多了空格）。**解决**：逐个点开 Error，用放大镜工具看未连接的脚；网络标签统一复制粘贴，别手敲。
2. **现象**：WS2812 不亮或颜色乱闪。**原因**：WS2812 数据脚要求 5V 电平，而 MCU GPIO 只给 3.3V；或灯带直接由 USB 5V 供电但与 MCU 没共地。**解决**：原理图上 WS2812 VCC 画 `+5V`、DIN 串 330Ω 电阻、GND 与 MCU 共地；必要时加电平转换。
3. **现象**：板子上电后无法下载程序。**原因**：BOOT 电路错——GPIO0 没有上拉，或按键接法反了（按下接到 3V3 而不是 GND）。**解决**：GPIO0 必须 10kΩ 上拉到 3V3，BOOT 键另一端接 GND；上电时按住 BOOT 再上电进入下载模式。
4. **现象**：LDO 输出纹波大、MCU 偶尔死机。**原因**：去耦电容只放了一个 0.1µF，且没有 10µF bulk 电容；或电容离电源脚太远。**解决**：LDO 输入输出各 10µF + 0.1µF，模组每个 VDD 脚就近 0.1µF；位置在 04 环节贴近电源脚。
5. **现象**：蜂鸣器不响甚至发烫。**原因**：GPIO 直接推蜂鸣器（无源蜂鸣器需要 PWM，有源蜂鸣器电流超 GPIO 灌流能力）。**解决**：用 NPN 三极管（如 S8050）驱动，GPIO 串 1kΩ 基极电阻，蜂鸣器走独立电源。
6. **现象**：画完原理图忘了导出 BOM，采购时对不上料。**原因**：没给每个器件关联立创商城编号。**解决**：放置器件时就从 LCSC 库选带编号的符号；画完立刻导出 BOM 核对。
7. **现象**：把 Strapping 引脚（GPIO45/GPIO46）随便接了外设，导致启动模式异常。**原因**：没看数据手册的 Strapping 引脚表。**解决**：查 ESP32-S3 硬件设计指南，GPIO0/3/45/46 按要求上下拉，不接普通外设。

## AI 必须逐项检查清单（防幻觉）

> **铁律：ERC 通过 ≠ 原理图正确。** ERC 只查"电气连接规则"（未连接引脚、输出短路等），查不出"LDO 压差不够、去耦电容离电源脚太远、USB 接错脚"这类**设计性错误**。AI（包括你自己）在生成或审查原理图后，**必须按下表逐项检查，并在回复里逐条给出 PASS/FAIL + 证据**；漏检或只说"应该没问题"视为未完成。
>
> 证据等级提醒：本清单是**静态原理图检查**，全部 PASS 只代表"图画得对"，不代表上电就能跑；真机上电（06 环节调试）才算最终证据。板级引脚事实一律以 `board-reference.md` 的板级合同为准，不在本清单新立引脚真相。

| # | 检查项 | 怎么从原理图验证 | 不通过会怎样 | AI 自检要求 |
| --- | --- | --- | --- | --- |
| 1 | 电源入口完整（USB/电池 → 保护 → LDO） | 顺电源链看：USB VBUS / 电池座 →（必要的保护：自恢复保险丝 / 防反接 / 电池充电管理）→ LDO 输入 → 输出 3V3；输入、输出各有 10µF + 0.1µF 电容到 GND | 反接烧板；无保护时电池短路起火；缺电容 LDO 振荡 | 逐条 PASS/FAIL，指出电源链上每个器件位号与输入输出电容容值 |
| 2 | LDO 压差够（输入 − 输出 ≥ dropout） | 查所选 LDO 数据手册的 dropout 电压：如 AMS1117 需 ≥1V 压差，3.3V 输出则输入必须 ≥4.3V（USB 5V 直供才够；若 LDO 前只有 3.7V 电池直供，AMS1117-3.3 会掉压）；低压差 LDO（ME6211 / RT9013，dropout 数百 mV）才可低压输入 | LDO 输出掉到 3V 以下，MCU 复位/死机、WiFi 掉线 | PASS 时写明"输入 X V − 输出 3.3V = 压差 Y V ≥ dropout Z V"；FAIL 给换料建议 |
| 3 | 去耦电容就近电源脚（0.1µF + 10µF） | 原理图上每个 MCU/模组 VDD 脚旁有 0.1µF 陶瓷电容（位号画在对应电源脚就近），LDO 输入/输出端有 10µF bulk 电容；容值、耐压标注齐全 | 电源纹波大、MCU 偶发死机、ADC 采样飘（物理距离在 04 环节落实） | 数一遍 VDD 脚数量 vs 0.1µF 数量，逐个给 PASS/FAIL |
| 4 | 晶振（若用裸芯片）负载电容与接法 | 若原理图含外部晶振：看两个负载电容（典型 12–20pF）是否接对、是否靠近芯片；用 WROOM 等成品模组时晶振在模组内，本项记 N/A | 不起振、串口乱码、时钟偏频 | 明确写"本板用模组，晶振 N/A"，或列出负载电容值与接法 |
| 5 | USB 线路（D+/D− 接对脚 + ESD/串联电阻） | 确认 USB 座 D+ 接 GPIO20、D− 接 GPIO19（ESP32-S3 原生 USB，具体以本板板级合同 `board-reference.md` 为准）；必要时串 33–47Ω 电阻、加 ESD 保护二极管到 GND；VBUS 5V 与 GND 连对 | 枚举不出 USB 口、下载失败、浪涌打坏 USB 外设 | 贴出网络名映射：USB-D+ ↔ GPIOxx，USB-D− ↔ GPIOxx，逐条 PASS/FAIL |
| 6 | 天线区域未误接 | 原理图上模组天线区无任何网络、电容、电阻引出（天线是模组内 PCB 天线，不在原理图接元件） | 天线被外接元件拉偏谐振频率，WiFi 距离极短 | PASS："天线区无外接网络"；FAIL 指出误接的网络 |
| 7 | 地与模拟/数字地处理 | 原理图上分清楚 GND 网络是否统一：数字地与模拟地（麦克风/功放）单点汇合，或经磁珠/0Ω 连接；汇合点明确，不是到处乱接 | 模拟音频底噪大、数字开关噪声窜进麦克风 | 描述/画出地汇合点，说明模拟地怎么走 |
