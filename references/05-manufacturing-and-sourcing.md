# 05. 打样与元器件采购（Manufacturing & Sourcing）

全流程的环节 05（在 00/00b/01/02/03（含 03a 面包板原型、03b 原理图）/04 之后；为避免序号歧义，统一以"环节 05"指代）。原理图（03）与 PCB（04）定稿后，把设计变成实物板并把零件买齐。**国内主线：嘉立创（JLCPCB）打样 + 立创商城（LCSC）配元器件 + 可选 SMT 贴片**。输入：Gerber 文件、BOM 清单、坐标文件；输出：到手可焊的 PCB 板与一袋元器件。

## 目标与通过标准

- 目标：用最少的钱、最短的等待，拿到一块能焊、能测、能跑起来的实物板，并知道每一颗料从哪来、为什么选它。
- 通过标准：
  - 能独立在嘉立创官网完成一次 PCB 下单（工艺参数会选、费用与交期能看懂）。
  - 能用立创 EDA 一键把 BOM 推到立创商城，缺料/禁贴料能识别并补手贴。
  - 能说出阻容等被动件的选型逻辑（去耦电容、上拉电阻取值），不是照抄别人 BOM。
  - 收货时能按 BOM 清单核对物料、按目检标准查板面。
  - 成本总账（PCB + SMT + 元器件 + 邮费）心里有数，且备件多买了易损/易烧件。

## 可复制操作与命令

本环节以网页下单为主，命令用于整理 Gerber、核对物料清单与打开工程目录。

### 1. 打样前：整理 Gerber 与 BOM（Windows PowerShell）

```powershell
# 进入你的硬件工程目录（按实际路径改）
cd D:\eb-build\my-ai-device\hardware

# 列出 EDA 导出的 Gerber/钻孔文件，确认该有的层都在（铜箔层、阻焊、丝印、钢网、钻孔）
Get-ChildItem -Recurse -Include *.gbr,*.gtl,*.gbl,*.gts,*.gbs,*.gm1,*.drl,*.xln | Sort-Object FullName

# 把本次要打样的 Gerber 文件夹压成一个 zip，方便存档/备份（不要改名后再上传，EDA 里直接下单更稳）
Compress-Archive -Path .\Gerber\* -DestinationPath .\gerber-backup-$(Get-Date -Format yyyyMMdd).zip -Force

# 打开工程文件夹，对照 04 环节的 3D 预览再看一遍板形与开孔
explorer .
```

macOS / Linux 对应写法：

```bash
cd ~/eb-build/my-ai-device/hardware
find . -name '*.gbr' -o -name '*.drl' -o -name '*.xln' | sort
zip -r "gerber-backup-$(date +%Y%m%d).zip" ./Gerber/
open .    # macOS；Linux 用 xdg-open .
```

### 2. 嘉立创 PCB 打样下单流程（网页操作，按顺序点）

1. 打开嘉立创官网 https://www.jlc.com/ ，登录后进入「PCB 下单 / 在线下单」。
2. 上传 Gerber 压缩包（或直接从立创 EDA Pro「一键 PCB 下单」，见下文）。
3. 工艺参数逐项确认（**零基础第一块板一律用默认推荐项，别加花活**）：

| 参数 | 新手推荐选择 | 说明 |
| --- | --- | --- |
| 层数 | 2 层 | 模拟/电源简单板足够；4 层费用与等待翻倍 |
| 板厚 | 1.6 mm | 默认通用 |
| 板尺寸 | 按设计（≤100×100 mm 才够低价/免费档） | 超尺寸会明显加价，以官网当日报价为准 |
| 颜色 | 绿色/黑色默认即可 | 异色（红/蓝/白/黄）常加钱，以官网当日为准 |
| 表面处理 | 喷锡（HASL）默认 | 无铅喷锡/沉金更贵，新手不需要 |
| 阻焊/丝印 | 默认 | — |
| 铜厚 | 1 oz 标准 | 大电流电源才需加厚铜 |
| 数量 | 先打 5 片（够焊坏） | 打样档费用与交期以官网当日为准 |

4. 确认费用与交期（**价格、运费、交期、免费/低价打样名额均以官网当日显示为准**；新手活动常有低价/免费打样额度，下单页会自动抵扣）。
5. 填收货地址 → 提交 → 付款。物流一般走顺丰/京东，**地址属于隐私信息，不要写进任何文档或提示词**。

### 3. 立创 EDA 一键下单（PCB + SMT 联动，最省事）

1. 在立创 EDA Pro（https://pro.easyeda.com/）打开你的工程。
2. 原理图 → PCB 一致且 ERC/DRC 无错误（见 03/04 环节验收）。
3. 菜单「下单」→「PCB 一键下单」：自动把 Gerber、BOM、坐标文件打包送进嘉立创下单页，省去手动导出上传。
4. 同一页面可勾选「SMT 贴片」：立创商城 BOM 会自动匹配库内可贴料（见下条）。

### 4. SMT 贴片 vs 手贴分工建议

- **交给 SMT 贴的料**：立创商城库内「可贴」的阻容（0402/0603/0805）、SOT 三极管、普通 IC 、LED 等——机器贴得比人手稳，省掉 0402 点焊的痛苦。
- **自己手贴的料**：大连接器、排针/排母、按键、蜂鸣器、电解电容、螺丝固定件、模组天线座、以及 SMT 库里「禁贴/缺料」的元件。
- **分工口诀**：小贴片交给机器，大插件/怕烫件自己焊。QFN 主控若在 SMT 可贴库内，强烈建议让机器贴（手贴 QFN 虚焊率极高）。

### 5. 元器件采购：立创商城 vs 淘宝

| 渠道 | 适合买 | 优点 | 注意 |
| --- | --- | --- | --- |
| 立创商城 https://www.szlcsc.com/ | 主控、常用 IC、阻容感、连接器 | 正品、可追溯、与 EDA/SMT 联动、有库存标注 | 单价小料略贵，但省心 |
| 淘宝/拼多多 | 成品模块（麦克风板、功放板、OLED 屏）、开发板、线材、外壳 | 便宜、模块即焊即用 | 散新/拆机件多，看差评与追评 |

**封装选择（零基础默认从大往小练）**：

- 电阻电容：先选 **0805**（好焊、看得清），量产/省空间再上 0603，**0402 尽量交给 SMT**。
- IC：先选 **SOT-23-5/6**（小信号）、**SOIC-8**（直插好焊替代 SOP-8）；**QFN 让 SMT 贴**，不要零基础第一次就手焊 QFN。
- 排针/排母：选 2.54mm 直插，万能好用。

**常见器件选型速查（取值与料号以数据手册和立创商城当日库存为准）**：

| 用途 | 典型器件 | 选型要点 |
| --- | --- | --- |
| LDO 3.3V | AMS1117-3.3 / ME6211 等 | 看最大电流、压差；电池供电选低静态电流 |
| I2S 功放 | MAX98357A | 模块或 SOIC 封装，接喇叭，注意 4Ω/8Ω 与功率 |
| I2S 麦克风 | INMP441 | 模块即焊即用，注意 LRCL/BCLK/SD 接线 |
| 可编程 RGB LED | WS2812B（5050 封装） | 数据线上串 330Ω 电阻，首端加 1000µF 电解 |
| 锂电充电管理 | TP4056（线性 1A）/ CN3165（开关降压，发热小） | TP4056 必加防反接与温度电阻；大电流选 CN3165 |
| 去耦电容 | 每颗 IC 电源脚旁 0.1µF + 一颗 10µF | 紧贴电源脚，回路最短 |
| 上拉电阻 | I2C/按键/BOOT 脚 4.7kΩ–10kΩ | 按键到地、上拉到 3.3V；别用 0Ω |

**正品与散新**：立创商城默认自营/授权，料号带「LCSC 编号」；淘宝买芯片问清「全新原装/散新/拆机」，散新价格低但可能氧化、批次不一，**主控与充电管理这类关键件建议走立创商城**。

**备件策略**：阻容、LED、按键、排针按用量 ×2 买；主控、功放、麦克风、充电管理、MOS 管这类**易烧件多买 1–2 片**；第一次打样 5 片板时，关键芯片直接备 3 套。

### 6. 收货核对

1. 快递到手先看外包装有无压烂、泡水。
2. PCB：按数量点片数；看板面有无划痕、焊盘脱落、丝印错位、板边毛刺；对着光看阻焊是否均匀。
3. 元器件：对照打印版 BOM 逐行打勾；**对有极性的件（电解电容、二极管、LED、USB、充电模块）拍一张丝印方向照存档**。
4. 缺料/错料立刻在立创商城订单里申请售后，别等焊上才发现。

### 8. DFM 与下单衔接

下单与收货时，把 04 环节"### 4.8 可制造性设计（DFM，量产前必查）"落到下单选项与收货核对上。

**下单时 DFM 相关选项怎么选：**

| 选项 | 打样（5 片手贴 / 少量 SMT） | 小批量 SMT 量产 |
| --- | --- | --- |
| 拼版 | 选"厂家自动拼版"，省钱省事 | 自拼 V-cut 或让厂拼，注明工艺边宽度 |
| 工艺边 | 不自己留，厂方加；靠边器件 ≥5mm | 自己留 5mm 工艺边，放定位孔 / Mark 点 |
| Mark 点 | 手贴可不要；选 SMT 则必须留 | 必须留全局 Mark（≥3 个对角）+ 密间距 IC 局部 Mark |
| 测试点 / 治具孔 | 排针引出即可 | 测试点排成 2.54mm 阵列，治具压针位对齐；需要厂方烧录时注明烧录口 |
| 表面处理 | 喷锡（HASL）默认 | 细间距 QFN 建议沉金（ENIG），共面性好 |

> 嘉立创下单页上传 Gerber 后会自动跑 DFM 检查报告，**有红色项必须逐条看懂并改板或在下单页备注**，别直接付款。

**收货核对加 DFM 检查项（与第 6 节收货核对一起做）：**

- 板边/工艺边完整，无崩边毛刺（V-cut 处残留连接正常即可）。
- Mark 点在位：裸铜圆无盖油、无氧化、位置与 PCB 一致。
- 定位孔/安装孔孔径与外壳匹配，孔边无毛刺。
- 测试点裸露未盖油，用万用表笔能直接点到 3.3V/GND。
- 丝印位号、极性标记、引脚 1 标记清晰不糊。

## 常见坑

1. **现象**：PCB 回来了才发现 USB 座/排针被外壳挡住，或安装孔位置错。**原因**：没做 3D 检查、没和外壳模型对齐。**解决**：下单前在 EDA 里开 3D 预览，把外壳/接口件叠上去看一遍；模板 C 里专门问这一条。
2. **现象**：SMT 贴回来的板上有几颗 IC 是空的（没贴）。**原因**：这些料不在立创 SMT 可贴库或缺料，下单时 BOM 匹配标红了没注意。**解决**：下单页逐行看 BOM 匹配状态，红色「禁贴/缺料」手动改为「不贴，自己焊」，并在收货后单独手焊。
3. **现象**：买回来的 0402 电阻用镊子都夹不起来、焊不上。**原因**：封装选太小，新手没有显微镜/热风枪。**解决**：第一版阻容全部用 0805；0402 交给 SMT 或直接换 0603。
4. **现象**：TP4056 充一会儿电芯片烫手、甚至冒烟。**原因**：PROG 电阻算错导致充电电流过大，或没加散热/选了开关降压却用了线性方案。**解决**：按 PROG 电阻公式核对充电电流（1A 约 1.2kΩ）；大电池/大电流换 CN3165 开关方案，手摸温度超过 60°C 立刻断电。
5. **现象**：买的 INMP441 / MAX98357A 模块焊上去没声音/没数据。**原因**：淘宝模块批次杂、引脚顺序和标称不符，或 VCC/GND 接反。**解决**：到手先用万用表测 VCC-GND 不短路再上电；上电前对照模块丝印再核一遍引脚，不要只看卖家商品图。
6. **现象**：打了 5 片板，第一片就把主控烧了，后面没主控可焊。**原因**：没买备件。**解决**：关键芯片（主控、功放、充电管理、MOS）下单时多买 1–2 片，阻容按 2 倍买。
7. **现象**：嘉立创报价比预期贵很多。**原因**：板尺寸超过 100×100mm、选了 4 层/沉金/异色板、加了阻抗测试。**解决**：第一版压到 2 层 1.6mm 绿油喷锡、≤100×100mm；高级工艺等第二版再上，价格以官网当日为准。
8. **现象**：收货发现丝印上 U1/U2 位置和原理图对不上。**原因**：EDA 里位号被手动改了但没更新到 PCB。**解决**：下单前用 EDR/DRC 跑一遍一致性，丝印位号、极性箭头、1 脚标识必须可见。
9. **现象**：SMT 回来板子贴得歪歪扭扭、QFN 偏位、飞件。**原因**：下单时没看嘉立创自动 DFM 报告的红字项，或画板时根本没留 Mark 点（见 04 节 4.8）。**解决**：上传 Gerber 后逐条过 DFM 报告；画板时按 04 节 4.8 留好全局 Mark（≥3 个对角）与密间距 IC 局部 Mark。

## 验收清单

- [ ] Gerber 已从立创 EDA 正常导出，层数/钻孔文件齐全

- [ ] 费用与交期已记录（注明「以官网当日为准」）
- [ ] BOM 已在立创商城匹配，红色禁贴/缺料件已改为手贴清单

- [ ] 易损/易烧件已多买 1–2 片备件

- [ ] 收货已核对 DFM 项（板边/工艺边完整、Mark 点在位、测试点未盖油）
