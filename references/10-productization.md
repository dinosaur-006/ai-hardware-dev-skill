# 10. 产品化：3D 打印外壳、电源设计与认证量产准备（Productization）

全流程的环节 10（收尾环节）。软硬件联调通过后，把"洞洞板 + 飞线 + 裸露电池"变成一个能拿在手里、能充电、能送人或售卖的东西：做外壳、做电源、过认证、备量产。输入：已联调通过的主板与固件；输出：可手持的成品样机 + 一份"如果要量产该走哪几步"的备忘。

## 目标与通过标准

- 目标：让 MVP 从"能工作"走到"能交付"——外壳能装下主板、电池能稳定供电、知道自用/送人/售卖分别要补什么手续。
- 通过标准：
  - 能说出外壳用什么工具建模、选什么材料、找打印服务还是自购打印机。
  - 能把 EDA 导出的板框 DXF/STEP 对齐到建模软件里，并开出按键/USB/天线/散热口。
  - 能给出电池容量、充电电流、升压/降压方案，并估算出续航。
  - 能分清"自用 / 送人 / 售卖"三档分别需要哪些认证（速览级，不背条款）。
  - 已想好开源发布用哪个 LICENSE、第三方组件怎么声明。

## 可复制操作与命令

本环节以 GUI 操作为主（建模软件、切片软件、买料），命令行只做目录与文件整理。

### 1. 建外壳设计目录

Windows PowerShell：

```powershell
New-Item -ItemType Directory -Force -Path hardware\enclosure\cad, hardware\enclosure\stl, hardware\enclosure\docs
```

macOS / Linux：

```bash
mkdir -p hardware/enclosure/cad hardware/enclosure/stl hardware/enclosure/docs
```

### 2. 从 EDA 导出板框给建模软件用

在嘉立创 EDA 专业版 / KiCad 里手动操作：

- 板框层（Edge.Cuts / 板框层）单独导出为 **DXF**（2D 轮廓），或整板导出 **STEP**（3D 含元件高度）。
- DXF 用于 Fusion 360 / FreeCAD 草图描边对齐；STEP 可直接插入做干涉检查。
- 把导出文件放进 `hardware/enclosure/cad/`。

### 3. 检查导出文件与打印件是否就位

Windows PowerShell：

```powershell
Get-ChildItem hardware\enclosure\cad\
Get-ChildItem hardware\enclosure\stl\ | Select-Object Name, Length, LastWriteTime
```

macOS / Linux：

```bash
ls -l hardware/enclosure/cad/
ls -lh hardware/enclosure/stl/
```

### 4. FDM 打印参数速查（切片软件里填）

| 参数 | 入门推荐值 | 说明 |
| --- | --- | --- |
| 材料 | PLA（新手）/ PETG（耐温耐摔） | PLA 易打印但偏脆；PETG 稍韧、稍难打 |
| 层高 | 0.2 mm | 越高越快越糙；0.12 mm 更精细更慢 |
| 壁厚 | ≥1.2 mm（约 3 条 wall line） | 外壳强度主要靠壁厚，不是靠填充 |
| 填充 | 15-20%（方格/蜂窝） | 外壳 20% 足够，别为了结实打 100% |
| 支撑 | 仅悬挑 >45° 时开 | 朝外朝上的开口不要加支撑，否则拆不干净 |
| 底裙/底 raft | 裙边（brim）即可 | 翘边严重再上 raft |

### 5. 打印服务 vs 自购打印机

- **打印服务（推荐给零基础第一版）**：淘宝 / 嘉立创 / 未来工场等按克收费，寄 STL 文件即可，PLA/PETG 单件十几到几十元，免维护、免调机。
- **自购打印机**：后续要反复迭代外壳再买；入门款约 ¥1000-2000，预留调试时间。
- 第一次外壳强烈建议先打 1-2 件试装验证，再批量打。

### 6. 建模工具零基础对比

| 工具 | 费用 | 学习曲线 | 适合 | 备注 |
| --- | --- | --- | --- | --- |
| Tinkercad | 免费（网页版） | 极低，积木式 | 第一个简单盒体 | 对齐精度有限，复杂装配吃力 |
| Fusion 360 个人版 | 免费（年收入 < 1000 美元的非商业用户，3 年可续） | 中 | 参数化建模、装配、对齐 PCB | 本环节首选；商业用途需付费 |

### 7. 结构与建模要点清单

- **与 PCB 对齐**：把 EDA 导出的板框 DXF 作为草图底图，定位柱/螺柱位置直接对应 PCB 安装孔。
- **按键开孔与行程**：轻触开关一般高出 PCB 3.5-5 mm；开孔直径比按键帽大 0.5-1 mm，柱高留 1-2 mm 按键行程。
- **USB 口开窗**：Type-C 座开口比实物宽 0.3-0.5 mm，位置与 PCB USB 座丝印对齐。
- **天线开窗**：板载 PCB 天线或 IPEX 天线下方 5 mm 内不要有金属，外壳对应位置镂空/开网格，别用金属片全封。
- **散热孔**：充电芯片（TP4056）、稳压芯片、功放贴壳位置开条形孔，别封死。
- **装配公差**：PCB 螺柱过孔比 M3 螺丝大 0.5-0.6 mm（Ø3.2 mm）；螺柱内孔攻 M3 打 Ø2.5 mm 底孔；卡扣留 0.2-0.3 mm 间隙。
- **外壳分件**：上盖 + 底壳两件，用卡扣或 M3 螺丝；接缝放在侧面，别放在正面。
- **防误触**：常用按键凹进壳面 1-2 mm；USB 口选带防尘塞的座或加软胶塞。

### 8. 打印后处理

- 去支撑：斜口钳先大块掰掉，小刀修残。
- 打磨：240# → 400# → 800# 砂纸递进；想上色再喷底漆。
- 攻丝：M3 用 Ø2.5 mm 钻头打底孔，丝锥垂直顺转，别硬别。
- 第一次打出来别组装死：先试装，公差不对就回 CAD 改尺寸重打。

### 9. 电源设计速查

**电池选型**

| 项 | 18650 圆柱 | 锂聚合物软包（LiPo） |
| --- | --- | --- |
| 容量 | 2000-3500 mAh，规格标准化 | 按尺寸定制，几百到几千 mAh |
| 形态 | 固定圆柱，要做电池仓 | 薄、可塞缝隙，形状自由 |
| 放电 C 数 | 普通动力型（持续 2-5C）即可 | 设备型 0.5-1C 够；电机负载选动力型 |
| 安全 | 需支架/仓，防短路 | 怕折怕压，两面贴青稞纸/PET 绝缘 |
| 入门推荐 | 有电池仓空间、想换电池 | 要薄、要贴外壳内壁 |

**充电管理**

- 入门首选 **TP4056**（ESOP8，单节锂电 CC/CV 线性充电，4.2 V 截止）；PROG 电阻设充电电流：`I_CHG ≈ 1200 V / R_PROG`（如 1.2 kΩ → 约 1 A，2 kΩ → 约 600 mA）。
- 买 **带保护的 TP4056 模块**（DW01 + 8205A 过充过放过流保护），新手别只买裸片自己搭保护。
- 输入用 Type-C 母座；5 V 进，BAT 接 3.7 V 单节电。
- CN3165 等更高效率/多节方案只在确实需要时再换。

**升压 / 降压**

- 3.7 V 锂电（3.0-4.2 V）→ 5 V：用现成升压模块（MT3608 类小板）给 USB 外设 / 功放供电。
- 3.7 V → 3.3 V：用 LDO（AMS1117-3.3，或更省电的 HT7333）给 ESP32-S3 和传感器供电；大电流射频段注意 LDO 发热。
- 电源链路：电池 → 充电保护 → 总开关/负载开关 → 各路 DC-DC/LDO。

**电量检测（参考 EasyInput 板 battery sense 思路）**

- 单节锂电 4.2 V 满 / 3.0 V 放空，ESP32-S3 ADC 最大 3.3 V，不能直接测。
- 电阻分压：R1=100 kΩ（Vbat 到 ADC）、R2=100 kΩ（ADC 到 GND），ADC 读到的电压 ×2 即电池电压。
- 固件里建对照表：4.15 V≈100%、3.7 V≈50%、3.4 V≈10%、3.3 V 以下报警关机。
- ADC 脚加 100 nF 滤波电容，开机稳定后多次采样取平均。

**低功耗**

- ESP32-S3 三档：Modem-sleep（WiFi 关、芯片跑）→ Light-sleep → Deep-sleep（仅 RTC 醒，μA 级）。
- 不用的外设（麦克风、功放、传感器）用 GPIO 控制负载开关/MOSFET 彻底断电，别只靠 MCU 进睡眠。
- 待机产品目标：平时 Deep-sleep + 按键/RTC 唤醒，而不是一直亮着 WiFi。

**锂电池安全与邮寄**

- 电池必须有过充过放保护（保护板或保护 IC），别裸电芯飞线。
- 电池别紧贴发热元件（TP4056、功放）；外壳留缓冲，别硬压电池。
- 航空/快递邮寄锂电池有运输限制（UN38.3 等）；数量大或对外发货前先问快递公司当日要求，自用本地携带问题不大。

### 10. 认证与量产准备（速览级，条款以机构官网当日要求为准）

| 情形 | 大致要做的事 |
| --- | --- |
| 自己用 / 送朋友 | 无需认证；把电池保护、绝缘做好即可 |
| 小批量国内售卖 | 含 WiFi/BLE 通常需 SRRC 无线电发射设备型号核准；RoHS 环保声明；是否在 CCC 强制目录以最新目录为准 |
| 出口美国 | FCC（SDoC 或 ID）；UL/ETL 看客户与渠道要求 |
| 出口欧盟 | CE-RED（含无线）、RoHS、REACH |
| 用蓝牙名称 / Logo | 蓝牙 SIG 会员资格与 QDID 列名 |

> 以上仅为入门路线图，**具体测试机构、费用、周期、目录清单以各机构官网当日要求为准**；真正售卖前再花一周专门核一次。

### 10.1 预合规摸底（送测前先自测）

正式送实验室前先自己摸一遍 EMI，能省掉复测来回。下面所有动作只做"摸底观察"，结论不作为正式认证结果，正式结论仍以机构实验室当日报告为准。

**打样后摸底动作清单**

- 时间点：**PCB 打样回来第一时间就摸**，别等外壳、别等功能全做完。PCB 阶段发现问题改板成本最低；外壳阶段再发现就要改模具，代价翻十倍。
- 就近可用的摸底手段（有什么用什么）：
  - 借/租实验室预测试时段：找朋友公司、孵化器，或按小时付费租 EMC 实验室，按辐射/传导的标准频带扫一遍。
  - 简易近场探头 + 频谱仪观察法：近场探头夹在关键时钟/开关电源线上，看频谱仪上有没有突出尖峰；不追求 dB 绝对值，只横向对比"加磁珠/串阻前后尖峰掉没掉"。
- 记录格式：建 `docs/precompliance.md`，每次摸底记：日期、硬件版本、固件版本、摸底手段、可疑超标频点（MHz 量级）、怀疑来源（哪根线/哪个芯片）、已试手段、尖峰相对变化、下一步打算。

**常见超标整改手段（改哪里 → 怎么验证）**

| 手段 | 改哪里 | 怎么验证 |
| --- | --- | --- |
| 展频（Spread Spectrum） | ESP-IDF menuconfig 里开 PLL/主时钟展频，把时钟能量摊到一段频带 | 频谱仪上原来的单根尖峰应变矮变宽 |
| 串阻削峰 | 高速时钟线、WiFi/MCU 晶振走线串小电阻（如 22-33Ω），压陡边沿 | 近场探头对比串阻前后尖峰幅度；同时确认功能没变差 |
| RC 吸收 | 开关电源肖特基/续流二极管端加 RC（如 100Ω + 470pF），吸收开关尖峰 | 摸开关节点频谱，尖峰应明显下降 |
| 磁珠 | 电源入口、模块电源脚、敏感信号线串磁珠（选目标频点下阻抗合适的型号） | 对比磁珠前后对应频带尖峰；量一下压降别影响供电 |
| 局部屏蔽 | 高辐射芯片（WiFi 模组、功放）加局部屏蔽罩或贴导电泡棉到壳壁 | 盖罩前后对比辐射频带；注意别压到板载天线下方 |
| 地平面缝合 | 多层板相邻地平面用过孔阵列缝合，减小地弹 | 改板后重测；摸底阶段只能先检查缝合过孔密度够不够 |

**与 04 环节"预合规预留（π 型滤波与磁珠位置）"的呼应**

04 环节在 PCB 上预留了 π 型滤波与磁珠位置（默认贴 0Ω 或不贴）。摸底超标时按下面顺序试，别一上来就改板：

1. 先在 04 预留的磁珠位贴一颗对应频点的磁珠，看尖峰掉多少。
2. 没用就换回 0Ω，去 π 型电容位调容值（先小后大，如 100pF → 1nF → 10nF），别一次上大电容把有用信号滤没。
3. 以上都不够再考虑局部屏蔽罩/导电泡棉。
4. 所有改动记录到 `docs/precompliance.md`；正式送测时把这张表交给实验室工程师，复测定位更快。

**预合规整改决策提示词**

```text
我做了一次 EMI 预合规摸底，最近一条记录如下：<贴 docs/precompliance.md 里最近一条>。可疑超标频点在 <如 240-250MHz 区间>，怀疑来源是 <WiFi 模组开关电源 / 40MHz 晶振 / USB 差分线>。04 环节在 PCB 上已预留 π 型滤波与磁珠位置。请按"先低成本、不改板"的顺序给我一个整改试验序列，每一步说清楚：改哪个预留位置、贴什么料（0Ω / 磁珠型号范围 / 电容容值范围）、用近场探头怎么判断有没有改善、如果变差怎么回退。不要让我直接改 PCB。
```

**量产成本与 MOQ 速览**

- 外壳：3D 打印打样（单件十几到几十元）→ 几十件可做硅胶复模 → 上千件才开注塑模（模具费数万起，MOQ 通常数千）。
- PCB/SMT：嘉立创小批量打样已覆盖；百片级贴片费用按贴片点数算。
- 包装：纸盒 + 说明书 + 质保卡，百套级可找印刷厂拼单。
- 新手第一年别碰注塑开模，3D 打印 + 硅胶复模足够验证市场。

**开源项目发布注意**

- 选 LICENSE（MIT / Apache-2.0 / GPL），仓库根目录放 `LICENSE`。
- 用到的第三方代码、图标、字体在 `NOTICE` 或 README 列出来源与协议。
- 照片里别露出个人信息、开发板背面的贴纸串号。

### 11. 固件升级与设备管理（产品化视角）

MVP 阶段设备少、版本靠手刷；要送人或小批量售卖时，必须有 OTA 与设备清单，否则几十上百台设备出问题没法远程救。本节从产品化流程与运维视角讲；OTA 分区、双 bank、bootloader 校验等固件侧实现见 `references/07-firmware-ai.md` 的"### 9. OTA 固件升级与版本管理"。

**11.1 产品化 OTA 发布管道**

一次正式发布要走完整管道，别"改完代码就直接推全量"：

1. CI 构建：main 分支合并后自动出固件 bin + SHA256 摘要。
2. 签名/校验：用私钥签固件包；设备端拉包后校验签名与摘要，防止被刷入非官方包。
3. 上传 OTA 服务器/CDN：固件包 + 版本号 + 变更说明 + 兼容性声明（最低支持从哪个旧版本升上来、不兼容哪些旧版本）。
4. 灰度：先放 1% / 10 台 / 一个批次，观察 24-48 小时。
5. 全量：灰度组无投诉、无异常回滚后再逐步放开到 100%。

**固件包元数据约定**

- 版本号用语义化版本：`MAJOR.MINOR.PATCH`（如 1.2.3），每次发布单调递增，设备端按版本号判断要不要升。
- 变更说明写"用户能感知的变化"，别只贴 commit hash。
- 兼容性：标注 `min_upgradable_from`——低于这个版本的设备要先升到中间过渡版，再升当前版。

**11.2 设备身份与版本管理**

- 序列号（SN）与 MAC 在产线烧录时写入 **OTP**（一次性可编程区，读多写少）；当前固件版本号存在 **NVS**（可反复擦写，每次升级成功后更新）。别把版本号写 OTP，否则回滚要重新烧录。
- 设备清单 `docs/devices.md` 模板至少列：SN、MAC、硬件版本（HW Rev）、出厂固件版本、首次激活日期、最近一次 OTA 版本、状态（在线/离线/返厂）。
- 批量查版本：设备每次开机/每次状态上报时把 `fw_version` 报到服务器，服务器侧按版本号分组统计；别让运营自己跑现场刷。

**设备版本上报 JSON 结构示例**

```json
{
  "sn": "HW2026XXXX001",
  "mac": "A4:CF:12:34:56:78",
  "hw_rev": "1.2",
  "fw_version": "1.2.3",
  "battery_pct": 87,
  "online": true,
  "last_seen": "2026-09-29T10:30:00+08:00"
}
```

**11.3 升级策略与回滚预案**

- 灰度策略：按批次号或按 SN 尾号分组（尾号里挑 1-2 个先升），服务器按组下发；别一次推全量。
- 服务器侧：保留"强制回滚到上一稳定版"的命令；发现新版本大面积问题时一键把灰度组拉回旧版。
- 设备侧：OTA 用双 bank（A/B 分区），新固件写到备用 bank，启动自检通过才切为启动 bank；自检失败自动切回旧 bank。别把新固件直接覆盖运行中的 bank。
- 断电中断恢复：升级过程中断电，设备重启后检测到"升级未完成"状态，重新进入下载流程；不要因为断电就变砖。这一条对应 07 环节的双 bank + 回滚实现。

**11.4 与 07 环节"### 9. OTA 固件升级与版本管理"的衔接**

- 07 环节讲"OTA 分区怎么切、双 bank 代码怎么写、bootloader 怎么校验"，是固件侧。
- 本节讲"谁来发布、怎么灰度、怎么回滚、设备怎么登记、版本怎么查"，是产品化与运维侧。
- 两边对应：07 的分区表 ↔ 本节的固件包元数据；07 的启动校验 ↔ 本节的签名/摘要；07 的设备侧回滚代码 ↔ 本节的服务器强制回滚命令。

**11.5 设备管理最小集**

不要一上来搭完整物联网平台，第一版先做这三件：

- 状态上报：版本号、电量、在线状态（上面 JSON 结构即可）。
- 远程配置下发：音量阈值、上报周期、开关类功能；服务器下发后设备应用并回 ACK。
- 日志回传（可选）：出错时设备把最近 N 条日志打包上传，别默认全量传，费流量。

### 12. 成本反推在量产阶段的应用

选型阶段做的成本反推（见 `references/01-platform-selection.md` 的成本反推小节）不是选完就结束，量产阶段要复核：

- 量产 BOM 成本复核：把 BOM 里每个料的实际下单价（含税、含运费）填回去，对比选型时估的单价；哪几项超预算 20% 以上要单独标红复盘。
- 量级折扣与 MOQ 对单价的修正：1 片模组和 1000 片模组单价差很多；MOQ 不够要拼单或找代理走小批量。具体量级折扣与单机成本估算方法见 `references/05-manufacturing-and-sourcing.md` 的 `### 7. 成本估算模板`。
- 目标价破位时的降配路径：单机成本压不到目标价时，按"先软性后硬性"顺序降配——
  1. 换模组容量（Flash/RAM 够用就行，别多买冗余）；
  2. 换屏幕（从彩屏换段码屏 / 从高分辨率换够用分辨率）；
  3. 换电池（容量按实测续航反推，别按最大余量买）；
  4. 最后才动结构（外壳材料、注塑件数）。
- 所有价格在文档里写"以当日供应商报价为准"，别写死数字。

## 常见坑

1. **现象**：外壳打出来 PCB 装不进去，差 0.2 mm。**原因**：建模按 PCB 名义尺寸画，没留装配公差。**解决**：板框轮廓每边放大 0.2-0.3 mm，螺柱过孔 Ø3.2 mm 过 M3 螺丝；先打一件试装再批量。
2. **现象**：按键按下去卡死或按不到。**原因**：开孔太小、柱高没留按键行程。**解决**：开孔比按键帽大 0.5-1 mm，按键柱高比开关高出 1-2 mm 行程；先在面包板上实测按键高度再建模。
3. **现象**：WiFi 信号变差、连接经常断。**原因**：金属外壳把板载天线完全包住。**解决**：天线对应位置外壳镂空或开网格，天线下方 5 mm 内不布置金属；用 IPEX 天线时把天线引到壳外。
4. **现象**：电池掉电快，或充电时芯片烫手。**原因**：充电电流设太大、升压/LDO 效率低、外设没断电。**解决**：小容量 LiPo 把 TP4056 充电电流设到 500 mA 以内；用 GPIO 控制外设电源域；实测各路静态电流。
5. **现象**：电量显示 50% 时突然关机。**原因**：直接拿空负载电压当电量，没考虑带载压降与放电曲线。**解决**：在实测负载下做电压-电量对照表，留 3.3 V 以下低压保护关机阈值。
6. **现象**：打印件表面全是支撑印、支撑粘死拆不下来。**原因**：悬挑面加了不必要的支撑或支撑密度太高。**解决**：切片只对外悬挑 >45° 加支撑，朝外朝上的开口不加；支撑密度 10-15% 即可。
7. **现象**：电池过放后再也充不进。**原因**：用了不带保护的裸 TP4056 充电板，没有过放保护。**解决**：买带 DW01+8205A 保护的 TP4056 模块，或在电池串里加独立保护板；固件到 3.3 V 主动关机。
8. **现象**：做好的产品寄快递被退回。**原因**：锂电池航空/陆运有运输限制。**解决**：少量自用随身带；对外发货前先问快递公司当日锂电池邮寄要求，必要时走陆运、独立绝缘包装。
9. **现象**：量产设备 OTA 升级到一半用户断电，再开机变砖起不来。**原因**：固件用单 bank 直接覆盖运行分区，升级中断电时分区里是一半新一半旧。**解决**：按 07 环节做双 bank（A/B 分区），新固件写备用 bank，校验通过再切启动 bank；启动失败自动切回旧 bank。
10. **现象**：外壳都开模了才发现辐射超标，改板等于模具报废。**原因**：预合规摸底太晚，PCB 定型后才查 EMI。**解决**：04 环节预留 π 型滤波与磁珠位置（默认贴 0Ω），打样回来立刻用近场探头 + 频谱仪摸底，按 `docs/precompliance.md` 记录；别等外壳做完再查。
