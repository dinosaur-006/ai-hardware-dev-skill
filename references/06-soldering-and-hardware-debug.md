# 06. 焊接与硬件调试（Soldering & Hardware Debug）

全流程的第 6 步。把到手的 PCB 与元器件焊成一块能通电的板，并用万用表/眼睛/闻味把它调到「不短路、电压对、能下载固件」的状态。输入：焊好一半的板；输出：一块电源轨正常、准备跑固件（07/08 环节）的实物。**铁律：先测短路再上电，先限流再全压。**

## 目标与通过标准

- 目标：零基础也能稳定焊出无虚焊、无桥连的板子，并按安全流程把电送上、把电源轨量对。
- 通过标准：
  - 能按「直插→小贴片→QFN/模组」顺序完成一块板的焊接，焊点光亮圆润。
  - 能背诵并执行「目检 → 测电源对地电阻 → 限流上电 → 测电源轨 → 逐外设验证」的上电 SOP。
  - 会用万用表的通断/二极管/电压/电阻四个最常用档位。
  - 常见故障（虚焊、桥连、极性反、电源短路）能对着现象定位到原因。
  - 第一块板上电时没烧任何东西；锂电池使用知道基本安全红线。

本环节以手动操作为主，命令用于找串口、看设备管理器、打开烧录/日志目录。

### 2. 焊接步骤（按顺序焊，别跳）

1. **先目检 + 放电**：戴手环摸一下接地金属；对光看 PCB 有无明显短路锡珠。
2. **焊最低最矮的件**：先焊电阻、电容、二极管（贴在板面上的）。
3. **再焊直插件**：排针、排母、电解电容、USB、按键、开关——直插件最后焊，方便翻身板子时支撑。
4. **焊点检查**：每个焊点应**光亮、圆润、呈圆锥状包住引脚**；发暗、颗粒状、球状 = 冷焊/虚焊。
5. **贴片手法**：
   - 0805/0603：焊盘上先拖一点锡 → 镊子夹元件到位 → 一端先固定 → 再焊另一端。
   - 排针/多引脚 IC：拖焊（刀头沾少量锡+助焊剂，匀速划过引脚），桥连用吸锡带+助焊剂拖走。
6. **QFN/模组注意**：
   - QFN 底部散热焊盘先在板上锡膏薄薄一层；对准后用烙铁头压中间或加热风枪（有热风枪再做）。
   - 手焊 QFN 极易底部虚焊，**第一块板的 QFN 主控尽量交给 SMT**；非要手焊，焊完用万用表二极管档逐个脚测对相邻脚有无桥连。
7. **有极性件**：电解电容白边/条纹是负极、二极管带横线端是负极、IC 1 脚有圆点/缺口、USB 金属外壳朝上——**焊前再核一次丝印**。

### 3. 上电调试安全 SOP（每次新板必走）

1. **目检**：放大镜扫一遍，找连锡、锡珠、漏焊、引脚歪、极性反。
2. **测电源对地短路（不开电）**：万用表拨到通断/蜂鸣档，黑笔接 GND（USB 金属壳最稳），红笔逐个点 3.3V、5V、VBAT 测试点。**蜂鸣响 = 短路，绝不上电**，先找桥连/焊反的件。
3. **测对地电阻**：拨电阻档，电源轨对 GND 应有几百欧以上；接近 0Ω 就是短路。
4. **限流上电**：用可调电源或 USB 限流线，先把电流限在 100–200mA、电压从低往上加。**一上电电流就冲到限流值 = 还有短路，立刻断电。**
5. **测各电源轨电压**：稳定后用直流电压档黑笔 GND、红笔测点：5V 应为 4.8–5.2V、3.3V 应为 3.2–3.4V、LDO 输入输出压差正常。
6. **测 GPIO 静态电平**：未配置的 GPIO 应为高阻或被上拉拉到 3.3V 附近，不该一直贴地。
7. **外设逐一上电**：先只供主控 → 下载固件点亮一颗 LED → 再挂麦克风 → 再挂功放 → 再接电池。**一次只加一个外设，出问题立刻能定位是哪一个。**
8. **锂电池安全**：
   - 锂电池必须带保护板（PCM），裸芯不要直接焊。
   - 充电时人在场，别过夜充；鼓包、发烫、异味立刻断电断电断电。
   - 焊接电池线时间别超过 3 秒，或先焊在保护板端子上；不要刺破、短路电池正负极。
   - 废电池用绝缘胶带包好正负极，丢电池回收点。

### 4. 万用表四档速用

| 档位 | 用途 | 红/黑笔怎么接 |
| --- | --- | --- |
| 通断/蜂鸣 | 查短路、查断线、查焊点通不通 | 任意接；响 = 导通 |
| 二极管 | 查二极管/LED 方向、查 IC 脚对脚有无桥连 | 红笔接正测压降（硅管 ~0.6V） |
| 直流电压 | 测 5V/3.3V/电池电压 | 黑笔 GND，红笔测点 |
| 电阻 | 测对地电阻、上拉阻值 | 断电测！带电测电阻会烧表 |

**技巧**：测短路时黑笔固定在 USB 金属外壳（最可靠的 GND），红笔逐个点测试点；测电压时手别碰金属笔尖，避免引入干扰。

### 5. 找串口 / 看设备管理器（Windows PowerShell）

```powershell
# 列出当前系统可见的串口（ESP32 下载后会枚举出 COMx）
[System.IO.Ports.SerialPort]::GetPortNames()

# 打开设备管理器，看「端口 (COM 和 LPT)」里有没有新出现的 COM 口、有没有黄色感叹号
Start-Process devmgmt.msc

# 打开固件日志目录，准备把上电调试现象记下来（路径按实际改）
explorer D:\eb-build\my-ai-device\docs
```

macOS / Linux 对应写法：

```bash
ls /dev/cu.* /dev/tty.*     # macOS 看串口
ls /dev/ttyUSB* /dev/ttyACM* # Linux 看串口
open ~/eb-build/my-ai-device/docs
```

### 6. 逻辑分析仪（可选，后置）入门

- 仅当你需要看 I2S（BCLK/LRCLK/SD）、按键编码器、I2C 波形时再买。
- 接法：GND 共地 → 通道 1 接时钟、通道 2 接数据；用 sigrok/PulseView 抓。
- 零基础第一阶段不必买，先用万用表 + 串口日志判断「有没有波形/有没有打印」即可。

## 常见坑

1. **现象**：一上电电源就短路、电流顶到限流。**原因**：电源轨对 GND 有桥连锡珠，或去耦电容/芯片焊反。**解决**：先别反复上电！断电用蜂鸣档逐点找短路点；重点查 USB 座旁、LDO 输入输出、电解电容极性。
2. **现象**：3.3V 只有 1.8V 或 0V。**原因**：LDO 输入没进来（USB 焊盘虚焊）、LDO 输出端被某个外设拉低、LDO 本身焊坏。**解决**：从 USB → 保险/磁珠 → LDO 输入 → LDO 输出逐段量电压，断点即故障点。
3. **现象**：串口怎么都枚举不出 COM 口。**原因**：USB 数据线 D+/D- 虚焊或接反、CH340/CP2102 没装驱动、板子没进下载模式。**解决**：先看设备管理器有无新设备/感叹号；量 USB D+/D- 焊点；EasyInput V2.0 板开机状态短按一次 BOOT 进下载模式，退出要关机重开。
4. **现象**：焊点看着亮但板子不工作（信号出不来）。**原因**：冷焊/虚焊——外观可能亮，但内部没连上。**解决**：放大镜重看可疑脚，烙铁头补一点助焊剂重熔；拨一拨元件看是否松动。
5. **现象**：相邻两个引脚被锡连在一起（桥连）。**原因**：拖锡时锡给多了。**解决**：加助焊剂，用吸锡带贴在桥上、烙铁压上去把锡吸走；别用手直接拽。
6. **现象**：功放一接喇叭就爆音/烧芯片。**原因**：MAX98357A 输出端直流偏置异常、电源去耦不够、或喇叭阻抗太低。**解决**：先断开喇叭，量输出端直流应接近 0V/中点电压；电源脚补 10µF + 0.1µF；确认喇叭 4–8Ω。
7. **现象**：INMP441 接了但采不到声音。**原因**：BCLK/LRCL/SD 接错、VDD 与 GND 接反、或 WS 没接对。**解决**：断电核丝印；上电量 VDD 应有 3.3V；用逻辑分析仪看 BCLK 有无时钟（后置工具）。
8. **现象**：摸芯片烫手不敢继续。**原因**：TP4056 电流过大、LDO 输入输出短路、或风扇/马达类负载堵转。**解决**：立刻断电；凉下来后量对应电源轨对地电阻；TP4056 核 PROG 电阻，必要时换 CN3165。
9. **现象**：手一碰板子就复位/死机。**原因**：没防静电，人体静电打坏 CMOS；或 GND 走线细、接触不良。**解决**：戴手环再摸板；量 GND 通路；关键芯片下次让 SMT 贴。

## 验收清单

- [ ] 焊接工具齐备（烙铁/焊锡/助焊剂/吸锡带/镊子/万用表）
- [ ] 焊接顺序正确（矮件→直插件→模组），有极性件方向核对过
- [ ] 焊点目检合格（光亮圆润、无连锡、无冷焊）
- [ ] 上电前已用通断档测过电源对地，不短路
- [ ] 第一次上电已用限流（≤200mA），未顶流
- [ ] 已实测 5V 与 3.3V 电压在正常范围
- [ ] 外设是逐个加上电验证的，没有一次全插满
- [ ] 已会用万用表通断/二极管/电压/电阻四档
- [ ] 锂电池使用已遵守安全红线（带保护板、人在场充电）
- [ ] 调试过程与读数已记到 `docs/debug-log.md`
