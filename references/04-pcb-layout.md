# 04. PCB 布局布线（PCB Layout & Routing）

全流程的第 5 步。原理图（03）通过 ERC 后，把器件摆到板子上、把线连出来，做成可发厂打样的 PCB 文件。输入：通过 ERC 的原理图工程；输出：通过 DRC、含 Gerber 的 PCB 工程，为 05 打样下单做准备。

> 原理图是"逻辑连接"，PCB 是"物理摆放+走线"。新手第一块板的目标不是"最优雅"，而是"能焊上、能跑、天线不被自己挡住"。

## 目标与通过标准

- 目标：在立创EDA（或 KiCad）里完成器件布局、关键走线、覆铜，跑通 DRC，并导出可发嘉立创打样的 Gerber。
- 通过标准：
  - 能说出本板选 2 层还是 4 层，以及理由。
  - 电源/数字/模拟/射频分区清晰，ESP32-S3 模组天线区净空无铜。
  - 去耦电容紧贴芯片电源脚，USB 走差分对，电源走线已加宽。
  - DRC 无违规，Gerber 已导出，生产前检查清单逐项打勾。
  - 知道哪些"常见坑"会导致板子打回来焊不上/连不上 WiFi。

## 可复制操作与命令

### 4.1 从原理图转 PCB

- **立创EDA专业版**：在原理图界面顶部菜单 → 设计 → 转换/更新到 PCB（Update PCB / 网表导入）。第一次转板时，所有器件会堆在 PCB 边框外，框选后拖进板框。
- **KiCad**：原理图界面 Tools → Update PCB from Schematic（F8），确认网表无报错后进 PCB Editor。

> 转板前务必确认原理图 ERC 已通过；否则网表会带错误进 PCB，后面越改越乱。

### 4.2 层板选择（2 层 vs 4 层）

| 项 | 2 层板（新手默认） | 4 层板（立创常免费打样） |
| --- | --- | --- |
| 成本 | 极低（首单常 0 元） | 立创 4 层打样常有免费/优惠活动 |
| 难度 | 低：顶层走线 + 底层地 | 中：多一个地层和电源层，需规划叠层 |
| 适合 | 简单最小系统、外设少、对天线敏感但用模组 | 外设多、电源电流大、要完整地平面 |
| 地平面 | 底层尽量整片覆 GND，不被走线切碎 | 第二层完整 GND 平面，信号更干净 |

**新手建议**：第一块板用 **2 层**即可；如果外设多（麦克风+功放+多路传感器），或想用立创 4 层免费打样额度，直接上 4 层，叠层按"顶层信号 / 第二层 GND / 第三层电源 / 底层信号"。ESP32-S3 官方指南推荐四层板，但用成品模组（WROOM-1）时模组内部已处理好射频，2 层也能跑通 WiFi。

### 4.3 布局（Placement）原则

按"分区摆放"，先大块位置再细节：

1. **接口靠边**：USB-C、电源座、按键、旋钮、排针全部靠板边——这样插线、按按键才不被挡住。先把板框 Mechanical 层画出来，接口沿边放。
2. **模块分区**：
   - 电源区：USB 座 → LDO → 大电容，放板子一角，电流走直线。
   - 数字区：ESP32-S3 模组 + 数字外设（按键/编码器/WS2812）放中间。
   - 模拟/音频区：INMP441 麦克风、MAX98357A 功放、喇叭接口单独一区，远离数字开关噪声；功放输出走线短而粗。
   - 射频区：ESP32-S3 模组天线伸出板边（见 4.4）。
3. **去耦电容就近**：0.1µF 去耦电容**紧贴模组 3V3 电源脚**，先于走线放；10µF 大电容放 LDO 输出端。
4. **晶振**（若用裸芯片而非模组）：紧贴芯片、下方不走线、用地包围。用 WROOM 模组时晶振已在模组内，不用管。

### 4.4 天线净空（ESP32-S3 最容易翻车的地方）

- ESP32-S3-WROOM-1 模组自带 PCB 天线，天线端**必须伸出主板板边外侧**，主板在天线投影区域内**禁止铺铜、禁止走线、禁止放器件**（keepout 禁布区）。
- 把模组的天线一端朝向板边，让天线"悬空"在板外；模组其余部分贴在板上。
- 不要在天线下方/周围覆 GND 铜，不要让其它走线贴近天线——这会直接把 WiFi 信号"短路"到地，导致距离极短或连不上网。
- 在 PCB 上用 Keepout/禁布层把天线投影区划出来，标上"天线净空，禁铜"。

### 4.5 布线（Routing）要点

| 走线对象 | 规则 | 原因 |
| --- | --- | --- |
| 电源线（5V/3.3V 主干） | 加宽到 0.8~1.0mm（约 30~40mil），过电流大再粗 | 压降/发热 |
| 普通信号线 | 默认 0.25~0.3mm（10~12mil） | 通用 |
| USB D+/D- | 走**差分对**，等长、紧密平行，不跨分割，长度控制在 50mm 内 | 差分阻抗 90Ω，保证 USB 通信 |
| I2S 时钟线（SCK/WS） | 短而直，远离 USB/电源噪声线 | 时钟敏感，长了串扰 |
| 喇叭/功放输出 | 短、粗，远离麦克风模拟区 | 防自激啸叫 |
| I2C（SDA/SCL） | 短，上拉电阻就近主芯片 | 总线 |
| 地 | 底层整片覆 GND 铜，打过孔（缝合孔）连接 | 完整地平面 |

- **覆铜**：2 层板底层整片覆 GND（ Pour → GND），并在覆铜上多打地过孔；顶层在空白处也可覆 GND 并打过孔缝合。覆铜后重新 Pour 一次让它避开走线。
- **不要先布线再想规则**：先在设计规则里定好线宽/间距，再走线（见 4.6）。

### 4.6 设计规则与 DRC

- **先设规则再布线**：立创EDA专业版 → 设计 → 规则设置；KiCad → File → Board Setup → Design Rules。新手用嘉立创默认 JLCPCB 工艺规则即可（线宽/间距默认 0.127mm/6mil，过孔 0.3/0.6mm）。
- 推荐起始值（新手够用）：
  - 最小线宽：0.2mm（8mil）
  - 最小间距：0.2mm（8mil）
  - 过孔外径/内径：0.6mm / 0.3mm
  - 电源线宽：≥0.8mm
- **DRC 检查**：立创EDA → 设计 → 设计规则检查（DRC）；KiCad → Inspect → Design Rules Checker。把"间距违规、未连接网络、过孔太小"全部清零。

### 4.7 生产前检查与导出 Gerber

发厂前逐项过：

1. **板框与外形**：Mechanical 层画好板边，四角留 M3 定位孔（3.2mm）或按外壳定。
2. **工艺边/拼版**：单板打样一般不用自己拼版，嘉立创会自动拼；但板上器件距离板边 <5mm 时要加工艺边，否则 SMT 贴不上。
3. **丝印**：丝印文字不要压焊盘（否则焊不上）；板名、版本号、引脚 1 标记、USB 方向都印上。
4. **定位孔/安装孔**：孔径与外壳螺丝匹配（M3 用 3.2mm 孔）。
5. **导出 Gerber**：立创EDA → 导出 → Gerber（直接一键"PCB 下单"跳到嘉立创，最省心）；KiCad → File → Plot 导出 Gerber + Drill 文件，再打包 zip 上传嘉立创/JLCPCB。
6. **3D 预览**：立创EDA 内置 3D 预览，KiCad 有 3D Viewer，转一圈看有没有器件干涉、丝印乱位。

> 导出 Gerber 后，嘉立创网页会自动做 DFM（可制造性）检查，有问题会列出。把 Gerber 文件单独存一个 `hardware/gerber/` 文件夹（05 环节下单用）。

## 常见坑

1. **现象**：打样回来 WiFi 距离极短、连不上网。**原因**：模组天线下方/周围铺了 GND 铜或走了线，天线被"短路"到地。**解决**：天线投影区设 Keepout 禁铜禁线，模组天线端伸出板边外侧，四周净空。
2. **现象**：去耦电容放了，但离芯片电源脚 2cm 远。**原因**：布局时先摆主芯片，忘了把电容挪到脚边。**解决**：放完主芯片立刻把 0.1µF 电容贴到电源脚旁边，再走短粗过孔到地。
3. **现象**：DRC 全绿，但焊出来发现丝印压在焊盘上，钢网对不上。**原因**：丝印文字没让开焊盘，或器件标号压在焊盘中心。**解决**：布局时把丝印移到焊盘外；生产前用 3D/DFM 看一遍。
4. **现象**：规则还没设就开始拉线，拉完才发现线太细要重拉。**原因**：先布线后设规则。**解决**：先在设计规则里定好线宽/间距/过孔，再布线；立创EDA 直接套用嘉立创默认工艺。
5. **现象**：USB 连不上电脑。**原因**：D+/D- 没走差分对、走线长且不平行、跨了地平面分割。**解决**：D+/D- 紧密平行等长走线，下方保持完整地平面，长度 <50mm。
6. **现象**：麦克风收到明显数字噪声/底噪。**原因**：模拟音频区（INMP441）紧贴开关电源或高速数字走线，地平面被切碎。**解决**：模拟区单独靠墙放，功放输出短粗，数字噪声线远离麦克风模拟走线，地平面保持完整。
7. **现象**：板子打回来发现器件贴不到板边、SMT 报错。**原因**：器件离板边 <5mm 没加工艺边。**解决**：靠边器件留足 5mm 边距，或让嘉立创自动拼版加工艺边。
8. **现象**：覆铜后地线阻抗反而变大、噪声变大。**原因**：覆铜是"孤岛"，没打足够地过孔与主地相连，或被走线切成碎块。**解决**：覆铜后多打缝合过孔（via stitch），保证整片 GND 连通，重新 Pour。

## 验收清单

- [ ] 已确定板层数（2 层 / 4 层）并说明理由
- [ ] 板框 Mechanical 层画好，定位孔/安装孔径已定
- [ ] 电源/数字/模拟音频/射频四区已分区，接口靠板边
- [ ] ESP32-S3 模组天线伸出板边，天线投影区已设 Keepout 禁铜禁线
- [ ] 0.1µF 去耦电容紧贴模组电源脚，10µF 电容在 LDO 输出端
- [ ] 电源主干走线已加宽（≥0.8mm），普通信号线按规则
- [ ] USB D+/D- 走差分对、等长平行、下方地平面完整
- [ ] 底层（及顶层空白）已覆 GND 铜并打缝合过孔
- [ ] 设计规则已设定，DRC 无违规
- [ ] 丝印未压焊盘，Gerber 已导出并存入 `hardware/gerber/`（交 05 下单）
